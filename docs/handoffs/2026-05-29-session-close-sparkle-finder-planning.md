## Key Decisions

### 1. Product Name And Brand

Sparkle Finder is the working customer-facing product name.

Use:

```text
Sparkle Finder by Sparkle Suite
```

The mark is an `SF` circular seal inspired by the Sparkle Suite `S` seal.

Brand rules:

- use main Sparkle Suite brand
- use warm, polished, soft, plain-English feel
- use blush/warm-white/pink/plum palette
- use `Playfair Display` for display headings
- use `DM Sans` for body/UI
- do not use the Amethyst skin/template
- do not imply official Bomb Party partnership

### 2. V1 Product Scope

V1 is not a customer-to-customer trading product.

V1 is a secured customer discovery hub that helps customers find:

- Sparkle Suite reps
- rep live shows
- rep trade boards / dance floors
- master jewelry library records
- Diamonds & Unicorns
- rep paths and next-show context
- collector and livestream gear through affiliate/shop links

Public visitors see a teaser/landing page. Useful hub areas require login.

### 3. Parked Scope

Do not build in V1:

- customer-to-customer trading
- customer buy/sell marketplace
- message board/social feed
- sponsored rep placement
- future rep signup sales from the hub
- Gold/Diamond memberships
- annual plans
- open-ended Nic-Nac chat
- full marketplace payments, escrow, shipping, or dispute mediation

### 4. Free Customer Account

Free customers should be able to:

- create a login
- browse the master live calendar
- browse Sparkle Suite rep directory
- browse aggregated rep trade boards / dance floors
- browse the master jewelry library
- browse Diamonds & Unicorns Library
- use normal manual search and filters
- open rep site/show/board paths
- browse affiliate/shop recommendations

Free customers should not be able to:

- create the full personal profile/collection experience
- use Silver Nic-Nac find-this-for-me assist
- submit uncataloged jewelry to the master database
- initiate customer-to-customer trade workflows

### 5. Silver Membership

The paid customer tier is called:

```text
Silver Membership
```

Pricing/terms:

- target `$4.99/month`
- monthly only
- no annual plan
- cancel anytime
- access remains active until the end of the paid month
- paid Sparkle Suite reps receive Silver for free while their rep account is active

Silver features:

- Nic-Nac Collector Assist
- `Nic-Nac, find this for me`
- customer profile
- customer collection from existing master jewelry library records
- collection showcase/highlight areas
- saved collection items and collector notes
- saved searches/watchlist
- email alerts when watched pieces appear if included
- saved reps/shows if included
- generous monthly Nic-Nac search access with internal usage controls

Silver should not be described as unlimited AI access.

### 6. Nic-Nac Customer Role

Customer-facing Nic-Nac should be bounded and practical.

Approved V1 use:

- help customers find pieces
- scan rep boards/dance floors
- return exact matches first
- return same collection/type or near matches second
- return rep, board/listing, rep site link, and next-show context
- answer basic Sparkle Finder feature questions

Do not build:

- open-ended chat
- pricing/value guarantees
- legal advice
- buy/sell facilitation
- trade mediation

### 7. Diamonds & Unicorns Library

Build a free Diamonds & Unicorns Library view.

Rules:

- powered by Bomb Party's own diamond/unicorn labels
- included in the normal master jewelry database
- highlighted as an exciting library offshoot
- no Sparkle Suite rarity score
- no extra rarity ranking

### 8. Monetization Direction

Revenue model:

- Silver Membership at `$4.99/month`
- paid Sparkle Suite reps receive Silver free
- affiliate/shop links for collector supplies
- affiliate/shop links for livestreaming gear and tools reps may want
- careful AdSense placements
- long-term strategic value is rep acquisition and retention

The customer hub should make reps want Sparkle Suite because it can drive traffic to them.
