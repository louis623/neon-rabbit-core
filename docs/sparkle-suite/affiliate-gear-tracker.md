## How to use this tracker

- Add a row when we decide a product is worth keeping on the shortlist.
- Mark `Approved` when Louis wants it kept as an active recommendation.
- Add the real Amazon affiliate link later after link setup is ready.

## Status key

- `Shortlist` = promising, but not locked
- `Approved` = chosen recommendation
- `Live` = published with affiliate link/site placement
