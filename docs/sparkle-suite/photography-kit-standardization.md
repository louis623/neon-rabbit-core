# Sparkle Suite Photography Kit Standardization

Status: accepted Phase 7.4 operating standard

This document turns the Phase 7.4 idea into a concrete operating standard.
The DUCLUS lightbox is accepted as the current baseline kit.

## Goal

Give every rep a "good enough" jewelry photo path that Nic-Nac can screen reliably.

The standard is intentionally flexible:

1. Lightbox is the baseline
2. White background is required
3. Camera can vary by rep
4. Nic-Nac screens sample output instead of trusting hardware labels

## Approved Kit Model

### Standard path: lightbox + rep device

Best for reps who already own a capable phone or camera.

Requirements:
- DUCLUS lightbox or equivalent clean white setup
- White background
- Rep-provided phone or camera
- Stable support or table placement

Use when:
- Nic-Nac screening passes sample photos
- Detail and framing are consistently acceptable

### Fallback path: same lightbox, more coaching

Best for reps who need another try on framing, angle, or consistency.

Requirements:
- Same lightbox
- White background
- Same rep phone or camera
- Nic-Nac sample-photo pass

Use when:
- Rep needs process coaching instead of new hardware
- Hardware upsells would slow onboarding unnecessarily

## Manual Validation Checklist

Validation checklist:

1. DUCLUS lightbox setup time
2. White background cleanliness
3. Shadow control
4. Reflective metal handling
5. Stone detail retention
6. Typical ring / necklace / bracelet framing
7. Repeatability with a normal phone workflow

## Pass / Fail Rule

Treat the kit as a pass if:

- clean jewelry photos repeatedly clear Nic-Nac preflight
- enhanced outputs usually end in `published` or `qa_review`, not `rejected`
- reps can repeat the setup without complicated instructions
- an average iPhone or Samsung-class device should be able to match or beat the baseline sample quality

Treat the kit as a fail if:

- even careful setup still produces dim, soft, or cluttered photos
- reflective glare overwhelms metal and stones
- the setup is too awkward for normal rep behavior

## Onboarding Screening Rule

Nic-Nac should screen one or more test photos during onboarding.

The photo passes if:

- preflight passes
- detail is strong enough
- background distraction is low
- framing is centered enough

The photo fails if:

- resolution is too low
- blur or detail risk is high
- lighting risk is high
- background distraction is high
- framing is too cramped or off-center

## Recommendation Flow

1. Ask the rep for a sample jewelry photo in their real setup
2. Run Nic-Nac screening
3. If pass: keep their current setup
4. If fail and lightbox is missing: require the lightbox + white background setup
5. If fail with lightbox present: coach framing, distance, and angle before changing hardware
6. If repeated retries still fail: handle as a manual exception, not a standard hardware upsell

Phase 7.4 can be marked complete when:

3. webcam standardization is either accepted or explicitly skipped
4. onboarding screening instructions are considered final enough for Phase 8
