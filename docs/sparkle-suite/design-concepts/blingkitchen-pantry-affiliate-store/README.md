# BlingKitchen Pantry Affiliate Concepts

Created August 17, 2026 as concept-only visual directions for Heather's review. These are not implementation specifications and do not represent changes to the live BlingKitchen site.

## Shared intent

Keep recipes as the primary reason to visit **In the Pantry**, while giving visitors a useful, transparent way to find the kitchen tools Heather actually uses. Any future affiliate links should carry a clear disclosure that Heather may earn a commission at no added cost to the shopper.

## Concepts sent to Heather

1. [Collection-led favorites](01-collection-led-favorites.png) — a prominent **Heather's Kitchen Favorites** collection sits above the recipes. Individual recipes surface a small “Used in this recipe” tool link.
2. [Utility-led tools](02-utility-led-tools.png) — visitors choose a practical path (recipe, tools, or favorites), then browse categories such as cookware, bakeware, prep, slow-cooker nights, and pantry staples.
3. [Story-led counter](03-story-led-counter.png) — a more editorial **From Heather's Counter** feature tells the story behind a few trusted tools and frames the store as a curated extension of the recipe box.

## Future-use note

If Heather selects or combines a direction, treat these as visual references only. Confirm the actual affiliate network, disclosure wording, destination-link model, and how product recommendations attach to recipes before implementation.
