# Sparkle Finder Affiliate Content Guide Index

Created: 2026-05-31

This folder contains first-pass guide topics for the affiliate readiness layer. These are content briefs, not product approvals. They are meant to help Sparkle Finder prepare useful, disclosure-ready guides before any exact affiliate products are chosen.

## Guardrails

- Keep the first pilot split evenly between collector essentials and rep/livestream setup gear.
- Do not name exact products, sellers, listings, ASINs, SKUs, prices, star ratings, review counts, retailer images, or live availability.
- Do not add affiliate links in these topic docs.
- Do not imply Bomb Party affiliation, approval, or sponsorship.
- Use every guide as a discovery-support resource, not a marketplace page.
- Move exact product candidates through `../louis-candidate-review-packet.md` before anything becomes `ready`, `live`, or app data.

## Standard Guide Structure

Each guide should include:

- audience and fit
- content outline
- category lanes to research later
- trust copy
- disclosure placement notes
- quality-screening prompts
- Louis approval gate

## Before Publication

- [ ] The guide has no exact product picks.
- [ ] The guide includes disclosure placement notes before any monetized recommendation area.
- [ ] The guide includes trust and issue-reporting copy.
- [ ] Candidate products have gone through the Louis packet.
- [ ] Program terms and disclosure requirements are recorded in `../program-tracker.md`.
- [ ] No guide language implies Sparkle Finder tested a product unless that is true.
- [ ] No guide language implies Bomb Party affiliation.
