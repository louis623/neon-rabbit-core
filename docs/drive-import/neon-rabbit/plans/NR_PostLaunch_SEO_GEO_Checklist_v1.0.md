## Pre-Flight

- [ ] SSL padlock is green on the live domain
- [ ] Site loads correctly on mobile
- [ ] Google Search Console — site added and verified
- [ ] Bing Webmaster Tools — site added and verified (msvalidate.01 tag in place)

---

## Technical SEO

- [ ] Title tags — unique, keyword-rich, per page
- [ ] Meta descriptions — unique, compelling, per page
- [ ] Canonical URLs — set correctly on all pages
- [ ] robots.txt — in place, welcoming AI crawlers by name (GPTBot, PerplexityBot, Claude-Web, ChatGPT-User, anthropic-ai, Googlebot, Bingbot + others)
- [ ] sitemap.xml — generated, all pages included
- [ ] Sitemap submitted to Google Search Console
- [ ] Sitemap submitted to Bing Webmaster Tools
- [ ] last-modified meta tag — set to today's date

---

## Open Graph & Social

- [ ] OG title — per page, unique
- [ ] OG description — per page, unique
- [ ] OG image — 1200x630, per page
- [ ] OG URL — canonical per page
- [ ] Twitter/X card — summary_large_image format, matches OG data

---

## Favicon & PWA

- [ ] SVG favicon — brand-appropriate design
- [ ] Apple Touch Icon — 180x180
- [ ] PWA manifest icons — 192x192 and 512x512
- [ ] theme-color — set to brand primary color

---

## GEO / Local SEO

- [ ] geo.position meta tag (lat;long)
- [ ] ICBM meta tag (lat, long)
- [ ] geo.region (e.g. US-OH)
- [ ] geo.placename (e.g. Ohio)
- [ ] GeoCoordinates in Schema.org
- [ ] PostalAddress in Schema.org (state and country minimum)
