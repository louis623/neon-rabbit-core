## Purpose

Single-source audit of every piece of evidence supporting (or needed to support) VA Compensation claims. Designed for two uses:

1. **Reference during drafting** — when writing the VetCom letter, HLR, or any supplemental, this file tells us exactly what we can cite, what's verbatim quotable, and what's still aspirational.
2. **Gap hunting** — single-pane view of what's missing per condition. Drives records requests and follow-up tasks.

**Verification status legend:**
- ✅ **VERIFIED** — Document confirmed in Drive or in Louis's possession; quote text confirmed
- 🟡 **PARTIAL** — Document exists but not fully reviewed, or some details unconfirmed
- ❌ **UNVERIFIED** — Cited in conversation but not yet documented; do NOT use specifics in filings until verified
- ⏳ **PENDING** — Records request filed or planned; not yet received

## Records Retrieval Plan

Two pulls plus one search, executed in parallel for maximum speed.

### Pull 1 — MyHealtheVet Blue Button (open item `e96442f0`)
- **Where:** myhealth.va.gov → Medical Records → VA Blue Button or VA Health Summary
- **Turnaround:** Immediate download
- **Expected content:** Recent VA medical notes, labs, prescriptions; possibly Golden VA prescription history if archived in VA system
- **Action:** Louis logs in, downloads everything available, drops in `/Neon Rabbit/` or shares via chat

### Pull 2 — C-file via VA Form 3288 (open item `6e17a276`)
- **Where:** AccessVA portal or mailed VA Form 3288
- **Turnaround:** 60-120 days historically (long lead time)
- **Expected content:** EVERYTHING — every claim, every C&P exam, every record VA reviewed for any decision
- **Why critical:** Tells us EXACTLY what records VA had when they wrote "GOLDEN VA CLINIC...not relevant." Without this, HLR argument is partially blind.
- **Action:** File request as soon as possible; clock starts on receipt

### Search 1 — Historical records file on Louis's computer (open item `daa3ccc1`)
- **Where:** Local file system, search terms: `Golden`, `Aurora`, `C-file`, `Cfile`, `VA Medical`, `VHA`, `MyHealtheVet`, `Blue Button`
- **File types:** PDF, DOCX, TXT — anything over ~10MB is a candidate
- **Locations to check:** Downloads, Documents, any "VA" or "Military" folder, OneDrive/Google Drive local sync folders
- **Turnaround:** 10-15 minutes if Louis can find it
- **Why important:** May already contain a previous C-file pull or comprehensive medical records bundle; could short-circuit Pulls 1 and 2

### Disambiguation 1 — "Online counselor" identity (open item `447c0e32`)
- **Where:** Personal email (search for telehealth provider names), bank/credit card statements 2018-2021, computer file search
- **Why important:** Resolves whether the sertraline prescriber was Golden VA telehealth (helps GAD argument) or a separate civilian provider (changes the HLR framing)
- **Action:** Personal sleuthing — not a VA records request

## Use Patterns

**Before drafting any filing or letter, Claude must:**
1. Check this inventory for what's VERIFIED vs. ❌/🟡/⏳
2. Quote ONLY from the "Verbatim Quotes" section above
3. Flag any UNVERIFIED claim being requested in a draft and ask Louis to verify before including
4. Cross-check that every cited document exists at its stated location

**When new evidence arrives:**
1. Add to master table with appropriate status flag
2. Update gap analysis for affected conditions
3. Extract verbatim quotes if document contains usable language
4. Update the Project Tracker file references section

**When evidence is invalidated or replaced:**
1. Mark in master table (do not delete history — supersede)
2. Update version history below
