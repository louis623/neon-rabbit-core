# Britt's Team Start Strong

Separate pilot repo for Brittany's new-rep onboarding and resource checklist.

## Purpose

Help new Bomb Party reps find answers, follow the setup path, and know when to ask Brittany.

This repo is intentionally separate from Sparkle Suite so the Brittany pilot can move quickly without changing Sparkle Suite launch scope.

## Demo Scope

- Clickable Start Strong checklist
- Official Bomb Party and FTC resource links
- Demo Brittany notes clearly marked as sample guidance
- Local progress tracking in the browser
- Saved questions for Brittany
- Floating Nic-Nac helper with canned, guardrailed prototype answers

## Domain Options

Preferred pilot deployment:

- `start.brittwithbling.com`

Possible later route if Brittany's domain host supports it:

- `brittwithbling.com/start-strong`

## Local Development

```powershell
npm install
npm run dev
```

## Content Sources

Official Bomb Party and FTC resources are linked in the app. Demo team guidance must be reviewed by Brittany before it is treated as real team guidance.
