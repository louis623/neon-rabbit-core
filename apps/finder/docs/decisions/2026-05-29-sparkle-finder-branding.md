# Sparkle Finder Branding Decision

Decision date: 2026-05-29

## Name

Working product name:

```text
Sparkle Finder
```

Brand relationship:

```text
Sparkle Finder by Sparkle Suite
```

Sparkle Finder is the customer-facing discovery hub in the Sparkle Suite ecosystem. It is not the rep-facing Sparkle Suite product, but it should feel clearly related.

## Logo / Local Mark

Use an `SF` circular seal inspired by the Sparkle Suite `S` seal.

Purpose:

- keeps the product visually connected to Sparkle Suite
- gives the customer hub its own mark
- avoids flattening the customer hub and rep product into one identity

## Visual System

Use the main Sparkle Suite brand system:

- Playfair Display for display/headline type
- DM Sans for body/UI
- blush/warm-paper/pink/plum palette
- warm, polished, plain-English feel
- premium without fake luxury
- customer-discovery language, not generic SaaS language

## Amethyst Decision

Do not use the Amethyst skin/template as Sparkle Finder's brand at this time.

Reason:

- Amethyst is a Sparkle Suite rep-site skin/template.
- Sparkle Finder should feel like an official customer-side product in the Sparkle Suite ecosystem.
- Using the main Sparkle Suite brand avoids making the customer hub feel like one rep template.

## 2026-07-03 Amethyst App-Skin Update

Louis approved moving the simplified mobile-first Sparkle Finder homepage/app UI toward the Sparkle Suite Amethyst customer-facing site skin.

This changes the earlier visual direction. Amethyst should be used as a visual theme direction for the app-style redesign, while Sparkle Finder remains the product name and customer-facing brand. Do not use "Amethyst" as broad customer-facing product copy.
