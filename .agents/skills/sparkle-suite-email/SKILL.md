# Sparkle Suite Email

Create warm, polished, plain-English messages that say the important thing early and respect the reader's attention. Before drafting or reviewing content, use `sparkle-suite-master-brand` and its email playbook.

## Sending boundary

Treat an email request as draft-only unless Louis explicitly asks to send a specific draft. Confirm the connected Gmail profile before creating or editing drafts. Never silently replace a different existing draft.

## Standard signature

For an email that needs a branded signature, place this below the sender's name and `Sparkle Suite`:

- A linked PNG lockup: `https://www.yoursparklesuite.com/email-signature-image`
- A linked landing-page address: `https://www.yoursparklesuite.com/`

Use the lockup at `248 × 81` display size. It is the approved warm-dark Sparkle Suite signature graphic: centered pink italic `S` in a light circle, with `SPARKLE SUITE` beside it. Do not substitute the favicon, an SVG, a social-share image, or an unverified image URL.

Before claiming the signature image works, verify that its public URL returns a PNG. When Louis asks for visual proof, inspect the Gmail draft itself; a successful HTTP response alone does not prove a mail client rendered it.
