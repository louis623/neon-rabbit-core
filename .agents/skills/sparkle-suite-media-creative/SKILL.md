# Sparkle Suite Media Creative

Create recognizable Sparkle Suite video artwork from the locked public brand. This skill governs visual packaging; it does not authorize publishing, uploading, or altering live product surfaces.

## Required brand sources

Before creating or reviewing an asset, read:

- `docs/sparkle-suite/brand/01-master-brand-spec.md`
- `docs/sparkle-suite/brand/02-messaging-pillars.md`
- `docs/sparkle-suite/brand/03-nic-nac-positioning.md` when Nic-Nac appears
- `docs/sparkle-suite/brand/04-brand-review-checklist.md`
- `docs/sparkle-suite/brand/05-public-site-version-lock.md`
- `docs/sparkle-suite/brand/08-production-site-design-kit.md`

For YouTube work, also use `sparkle-suite-youtube`. For TikTok or YouTube Shorts, read:

## Choose the mode

- **YouTube thumbnail:** read `references/visual-system.md`, then use the approved 16:9 reference in `assets/approved-nic-nac-live-calendar-thumbnail.jpg` as the default family resemblance.
- **Shorts or TikTok cover/first frame:** read the short-form section of `references/visual-system.md`; translate the same brand into a native 9:16 composition rather than stretching the thumbnail layout.
- **Supporting media:** use the same system for poster frames, background plates, title cards, end cards, and branded overlays. Keep each deliverable tied to the actual video message.

## Non-negotiable assets and product truth

- Use `assets/sparkle-suite-s-seal.svg` for the canonical product S mark. Use `assets/sparkle-suite-youtube-avatar.png` only when a filled channel-avatar treatment is appropriate. Do not ask an image model to redraw or approximate either mark.
- If a product screen appears, use a real screenshot, screen recording, approved demo, or a faithful crop supplied by the user or repository. Never generate a fake Sparkle Suite dashboard, workflow, metric, or customer site.
- Generative imagery may create backgrounds, abstract calendar motifs, atmosphere, hands, or metaphorical elements that do not imply unsupported functionality.
- Keep Nic-Nac useful and grounded as built-in rep support. Do not turn it into a robot, mascot, generic chatbot, or AI spectacle.

## Workflow

1. Identify the platform, asset role, video topic, exact visible text, and available real captures.
2. Verify current platform dimensions, file formats, upload limits, and safe-zone guidance from the platform's official documentation when those details affect delivery.
3. Build one strong focal idea. Keep thumbnail copy short enough to read at phone size and avoid repeating the full video title by default.
4. Use the built-in image generator for raster concepts or targeted edits. Preserve existing compositions aggressively during edits. Use deterministic compositing for the official S seal and real product captures when exact fidelity matters.
5. Export at the verified aspect ratio and pixel dimensions. Provide an upload-ready JPG and a lossless PNG when both are useful; report dimensions and byte size rather than assuming compliance.
6. Inspect the final image at full size and thumbnail size. Check spelling, crop safety, contrast, logo fidelity, product truth, and file constraints before handoff.

## Quality gate

- Looks like the approved Sparkle Suite public brand: blush/warm white, accent pink, plum/brown ink, Playfair-style display type, DM Sans-style supporting type, generous space, refined borders, and restrained shadows.
- Reads in one glance and remains legible when reduced.
- Feels warm, polished, calm, and useful—not generic SaaS, creator-guru, neon tech, loud influencer glam, or fake luxury.
- Uses one or two clear visual ideas, not a crowded collage.
- Contains no fabricated product UI or unsupported claim.
- Uses the complete pink S seal, including its pink circular outline.
- Final deliverables are saved outside temporary/generated-only storage and include verified platform-ready dimensions.
