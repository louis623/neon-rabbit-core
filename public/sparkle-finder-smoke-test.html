Keep Sparkle Finder open in one tab and this checklist open in another. For each item, try the steps in plain English, mark Yes if it works, or mark No if it does not. When you mark No, a feedback box opens so you can describe exactly what happened.

Open Sparkle Finder
1. Open the route Use each Open button, or click through from the homepage if the item tells you to.
2. Try the thing Click the button, use the browser Back button, resize if needed, and watch for weirdness.
3. Mark Yes or No If it fails, write what you expected, what happened, and anything you noticed visually.
